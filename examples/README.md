# Runnable examples

Start with the example closest to your own use case:

- [`custom_task/`](custom_task/): build and validate a task from generic CSV
  files, without assuming TREC formats.
- [`custom_router/`](custom_router/): read only participant-visible inputs,
  produce frozen route choices, and compare them with fixed routes.
- [`python_api/`](python_api/): call WorthIR from Python instead of the CLI.
- [`trec_walkthrough/`](trec_walkthrough/): convert qrels and TREC runs into a
  WorthIR task.
