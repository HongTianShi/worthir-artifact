# RQ3：可恢复效用的来源

`query_strata.csv` 使用完整路线结果将每个评测集划分为：

1. 最便宜路线的有效性不低于任何付费路线；
2. 付费路线提高有效性，但增益不足以抵消成本；
3. 付费路线能够提高效用。

贡献列表示该分层对策略相对开发集选定固定路线的平均效用增益所作贡献。各分层贡献
之和等于任务级增益。

`top_decile_switching.csv` 回答一个更窄的诊断问题：路线选择时可用的信息能否识别
最便宜路线已经达到最高效用的查询？查询按该事件的预测概率排序，最高 10% 从固定路线
切换到最便宜路线，其余查询保留固定路线。该实验衡量效用转化，而不仅是分类准确率。

这些分层和预测诊断是在原始任务结果可用后定义的，用于解释已观察增益，而不是提供
新的验证性检验。
