# 数据与模型条款

WorthIR 自有源码和文档采用根目录 MIT 许可证发布。第三方数据字段和衍生记录保留
其上游条款，本仓库不对其重新授权。

- **MS MARCO/TREC-DL：** 发布内容保留 97 个官方评测 topic、路线选择时 BM25
  摘要、动作和路线结果。MS MARCO 的非商业研究条件及 TREC 适用访问条件继续生效。
  不包含 passage、qrels 和完整排名。
- **FEVER：** 发布内容包括官方 claim 和标签，因为它们用于绑定 13,332 查询评测
  ledger。FEVER 公布的数据许可证声明（包括适用的 Wikipedia 或 CC BY-SA 条款）
  继续生效。不包含 Wikipedia 快照和检查点。
- **2WikiMultiHopQA：** 所含问题/支持信息衍生记录是对采用 Apache-2.0 许可证的
  上游版本修改后得到的研究记录。任务显示名称为 2Wiki-Structured；`structured_v2`
  仍是稳定的机器可读任务 ID。
- **MuSiQue：** 所含问题、分解、标题、答案和支持信息衍生记录是对 CC BY 4.0
  上游版本修改后得到的研究记录，并在 `THIRD_PARTY_NOTICES.md` 中注明来源。
- **BEIR/FiQA 与模型检查点：** 只包含精简诊断结果或模型标识符。请从官方来源获取
  语料库和权重，并遵守适用条款。

本 artifact 不包含任何凭据、API token、受许可限制的供应商导出或私有云对象。
