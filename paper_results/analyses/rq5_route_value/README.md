# RQ5：特定路线的边际价值

RQ5 将查询难度与某个具体检索操作的边际效用区分开来。精简文件覆盖三种机制。

- **候选可达性与重排深度。** FEVER 记录按 BM25 列表中首个相关证据页面的排名
  对查询分组。当路线重排深度能够到达该页面时才可能产生帮助；如果相关页面不在
  共享的前 200 个候选中，任何付费路线都无法恢复它。
- **操作与失败的匹配。** 在 2Wiki-Structured 上，将真实图扩展与度数匹配的随机
  及打乱对照比较。在 MuSiQue 上，将真实分解内容与打乱或错误分解比较。
- **路线选择时的可预测性。** 使用查询特征、第一阶段分数分布特征及两者组合预测
  特定路线的边际效用。只对评测端可见的难度单独报告，绝不作为路由器输入。

机器可读任务标签 `Structured-v2` 是 2Wiki-Structured 的历史标识符。所有文件
都是结果产生后的机制诊断，不能据此确立因果效应。
