# Full Replay Guidance

This directory documents how the released compact ledgers relate to raw retrieval reconstruction. It intentionally contains guidance rather than large corpora, indexes, model checkpoints, or licensed data.

- `RESOURCE_REQUIREMENTS.md` gives the hardware, storage, time, and dependency expectations that should be read first.
- `CANONICAL_TREC.md`, `FEVER.md`, and `MUSIQUE.md` describe task-specific reconstruction inputs and route execution.
- `STRUCTURED_AND_DIAGNOSTIC.md` covers Structured-v2 and the remaining diagnostic surfaces.

The normal artifact path does not require full replay. Use these documents only when rebuilding raw route outcomes, and do not describe compact ledger reproduction as equivalent to corpus/index reconstruction.
