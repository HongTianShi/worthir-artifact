# RQ3 Utility-Source Data

`query_strata.csv` contains the released task-level routing-opportunity strata and their utility contributions. `top_decile_switching.csv` contains the complementary high-opportunity switching diagnostic.

These are post-outcome evaluator analyses: they explain where observed policy differences arise and are not inputs to the router. Preserve the stratum definitions and utility-point scaling when regenerating figures or tables.
