# 2Wiki-Structured replay

`public/` is the action surface. `organizer_private/` contains the complete
2,000-query, five-route evaluator ledger and grouped references. Policies may
use only the public surface.

The stable task ID is `structured_v2`; the display name is
2Wiki-Structured. The paper reproduction command scores the grouped OOF action
vector through the task scorer. Reference definitions are in
`../../docs/REFERENCE_SEMANTICS.md`.
