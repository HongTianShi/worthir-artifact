# RQ4：稳健性

已发布摘要将三类敏感性分析分开：

- 2Wiki-Structured 在三个测试成本权重下分别完整重新拟合和选择。
- 随后固定其标准策略，在 816 个单调成本方案下重新评分；该检查针对预先声明的
  成本族，而不是任意成本。
- FEVER 保持同一个已训练有效性预测器，但在每个成本权重下重新计算路线选择；
  MuSiQue 则重新评估在主要设定下选出的策略。

`data/structured_candidate_recurrence.csv` 使用不接触目标的频率规则，移除与最常见
候选文档相关的查询，然后重复完整 OOF 拟合。`data/model_and_fold_summary.csv`
记录学习器类别和折叠分配检查。

FEVER 的候选共享图在全部 13,332 个评测查询上形成单一连通分量，而且每个评测查询
都与开发集共享至少一个候选，因此无法在该构造下进行候选不相交的重新拟合。候选 ID
不是路由器特征；该结果诊断的是依赖性，而不是对候选身份的直接使用。
