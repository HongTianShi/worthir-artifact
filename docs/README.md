# Guides

Choose the guide that matches the question you are trying to answer:

- [`ADAPT_TO_NEW_TASK.md`](ADAPT_TO_NEW_TASK.md): define queries, routes,
  prerequisites, public costs, outcomes, and router choices for a new task.
- [`COST_AND_LAMBDA.md`](COST_AND_LAMBDA.md): decide which costs are public,
  when they become known, and how to declare the cost preference.
- [`OUTPUTS.md`](OUTPUTS.md): interpret participant-facing scores and
  organizer-only diagnostics.
- [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md): repair installation, environment,
  download, and platform problems.
