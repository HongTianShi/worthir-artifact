# 参照与区间语义

WorthIR 将可部署选择与只对评测端可见的参照分开。以下标签表示信息集合，而不是强度
逐渐提高的算法。

| 标签 | 含义 | 部署属性 |
| --- | --- | --- |
| `F_dev` | 在开发数据上选择一条固定路线，随后冻结 | 对已注册评测可部署 |
| `A_dev` | 在开发数据上选择自适应方法类别和超参数，并在接入评测结果前冻结 | 对已注册评测可部署 |
| `A_OOF` | 每个查询的动作来自未使用该查询或其注册分组选择的模型，再拼接为完整动作 | 合法的分组交叉拟合估计 |
| `F_OOF-dev` | 每个折叠的固定路线根据该折叠开发分区选择 | 合法的分组固定参照 |
| `F_OOF-TIH` | 每个折叠的固定路线在观察该折叠测试结果后选择 | 只用于评测端诊断 |
| `F_TIH` | 在观察全部测试结果后选择一条固定路线 | 只用于评测端诊断 |
| `O_TIH` | 为每个测试查询分别选择最高效用的已注册路线 | 只用于评测端的路线集合内 Oracle |

当分母为正时，已恢复空间为：

```text
kappa_ref = [U(A) - U(F_ref)] / [U(O_TIH) - U(F_ref)]
```

它是在已发布状态和路线集合内，受测合法过程恢复的经验比例，而不是 Bayes 极限或
信息论极限。

## 各任务的解释

| 任务 | 固定参照 | 自适应结果 | Oracle | 信息边界 |
| --- | --- | --- | --- | --- |
| Canonical TREC-DL | 开发集选定的 CE | 冻结的合法基线；受测策略保持固定动作 | `O_TIH` | 公共历史 topic；在接入精简结果前冻结动作 |
| FEVER | `F_dev`，在此等于 `F_TIH` | `A_dev`，在官方训练集中的开发 claim 上训练和选择 | `O_TIH` | 动作在接入官方共享开发集证据前验证 |
| Structured-v2 | `F_OOF-dev` 和 `F_OOF-TIH` | 支持标题连通分量上的 `A_OOF` | `O_TIH` | 每个查询动作来自排除其注册连通分量的折叠 |
| MuSiQue | `F_dev`，在此等于 `F_TIH` | 官方验证集上按流程冻结的 `A_dev` | `O_TIH` | 在官方验证集评分前冻结训练/开发选择 |
| Hyperlink10k | 各数据划分的开发集固定参照和测试后见参照 | 冻结的划分回放动作 | 各划分内 `O_TIH` | 存在依赖的回顾性规模/路线压力测试 |
| Dense-standard | 由数据集决定的 `F_dev`，等于归档的 `F_TIH` | 历史 20 次划分自适应回放 | `O_TIH` | 五数据集同分布回放；数据集身份是合法状态 |

## 区间与范围提醒

`paper_reproduction/inputs/table3_recoverability.csv` 中的范围字段并不属于
同一个置信区间 family：

- FEVER 在共享 gold 页面/归一化 claim 连通分量上重采样；
- Structured-v2 在支持标题连通分量上重采样，分组构造完成后冻结学习器和动作；
- MuSiQue 报告已注册的官方验证集诊断区间；
- Hyperlink10k 和 Dense 报告各自已注册的划分回放范围。

有限 ledger 上的精确对比是主要结果。各任务自身的 README 和报告说明重采样单位及
保持固定的内容。
