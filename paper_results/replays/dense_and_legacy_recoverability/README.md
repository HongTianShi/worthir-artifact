# Dense and Legacy Recoverability Readouts

This directory groups compact retrospective outputs for Dense-standard, Hyperlink10k, and related legacy recoverability diagnostics that are not packaged as a full task-local replay surface.

The CSV and JSON files document baseline semantics, recoverability summaries, and dependence-aware intervals. They support scope and compatibility analysis rather than a new independent leaderboard result. Dataset-specific effectiveness measures and cost schedules remain task-local and must not be combined into one scalar comparison.
