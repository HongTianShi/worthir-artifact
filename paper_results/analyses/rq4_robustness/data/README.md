# RQ4 Robustness Data

This directory contains compact sensitivity summaries for cost preference, FEVER candidate dependence, model/fold variation, and structured candidate recurrence.

The files combine checks with different response modes: some rescore frozen actions, while others refit or reselect a policy. Consult the parent RQ4 README and accepted appendix before comparing rows. These summaries are robustness evidence, not additional primary tasks.
