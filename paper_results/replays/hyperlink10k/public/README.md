# WorthIR Hyperlink10k participant surface

This package exposes only purchase-time legal state, a five-view route
registry, cumulative operation costs, and five frozen master split assignments.
For one seed, submit exactly one registered view for every public test
`query_uid`, then run `validate_submission.py`.

The task reranks the dataset-provided context-title candidates. Hyperlink views
purchase additional corpus-derived text evidence for scoring those candidates;
they are not open-corpus candidate retrieval. Public IDs/questions remain
joinable to the public source dataset, so the contract enforces timing and
field separation rather than cryptographic label secrecy.
