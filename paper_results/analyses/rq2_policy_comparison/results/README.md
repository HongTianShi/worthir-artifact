# RQ2 Comparison Results

These CSV files are compact readouts for the cross-task and FEVER-specific policy comparisons. They include matched-policy utility differences, Holm-adjusted tests, uniform-random run summaries, expected-cost controls, query–route matching diagnostics, and the FEVER warm-online latency audit.

The main result tables use the paper's terminology and rounding. Some files are supporting diagnostics rather than primary evidence. Cross-task utility values must not be aggregated because task-specific effectiveness measures and cost units differ.
